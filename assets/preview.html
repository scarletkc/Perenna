🎨 Visual Elements

Stable visual cues used across the asset set:

1. P Mark

The curved mark forms the letter P and suggests memory that persists across agent sessions.

2. Git History

The vertical spine and branching paths reference Perenna's Git-backed Markdown history.

3. Shared MCP Access

The connected nodes represent MCP clients accessing shared memory, with the central glow referencing semantic retrieval.
